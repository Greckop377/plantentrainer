# PlantenTrainer

Leertool om plantennamen (familie, geslacht, soort) en de praktijkkenmerken van
tuinplanten in te oefenen. Gemaakt voor de opleiding Tuinaanleg en Groenbeheer.

De wetenschappelijke namen zijn geverifieerd tegen de GBIF-backbone
(`api.gbif.org/v1/species/match`). De foto's komen van Wikimedia Commons, staan onder
een vrije licentie en zijn voor het web verkleind; fotograaf en licentie staan bij
elke plant op de fiche.

Dit is de gepubliceerde webversie — ze wordt automatisch klaargezet vanuit het
bronproject en niet rechtstreeks bewerkt.
